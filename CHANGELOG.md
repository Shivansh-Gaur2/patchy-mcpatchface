# Changelog

## 0.3.0 — 2026-09-13

- Added a context-budget workflow: targeted retrieval first, then progressive widening only when evidence changes the design or proof plan.
- Added compact TOON receipts for uniform evidence rows such as impact, reuse, and verification records; configuration and prose stay in their native forms.
- Added a solution challenge that compares an incumbent design with one meaningful alternative when the problem warrants it.
- Tightened reports so they distinguish observed evidence, inference, unknowns, and residual risk without turning an answer into a repository dump.

## 0.2.1 — 2026-09-13

- Pointed Codex marketplace installation at the published `master` branch.
- Bumped the plugin version so the corrected release can be refreshed cleanly.

## 0.2.0 — 2026-09-13

- Added a repository marketplace catalog and generated plugin payload for reproducible Codex installation.
- Added a Codex plugin manifest and root marketplace identifier.
- Split Patchy into focused build, rummage, clipboard, and help skills.
- Added portable `AGENTS.md` and Copilot instruction fallbacks with a drift check.
- Added package validation, GitHub Actions, and named benchmark task contracts.
- Documented what Patchy supports today and what it does not claim.

## 0.1.0 — 2026-09-13

- First public Patchy workflow, examples, proof tiers, mascot, contribution guide, and benchmark plan.
