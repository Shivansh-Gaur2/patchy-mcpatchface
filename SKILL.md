# Patchy

Portable entry point for Patchy. Read and apply the canonical [Patch workflow](skills/patchy/SKILL.md).

For focused tasks, use the matching skill when available:

- `patchy-rummage` maps a behavior path without editing.
- `patchy-review` reviews a change against its request and repository conventions.
- `patchy-factory` coordinates an explicitly requested staged, multi-agent job; the builder follows `patchy`.
- `patchy-help` explains the available entry points.

`patchy-clipboard` remains as a compatibility alias for the review workflow.
