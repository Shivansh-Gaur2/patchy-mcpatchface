# Patchy Help

Use:

- `patchy` for a feature, bug fix, refactor, or non-trivial implementation.
- `patchy-rummage` to understand code or business logic without edits.
- `patchy-clipboard` to audit an existing diff for scope, reuse, and proof gaps.

The shared promise is simple: protect stated constraints, find the behavior and the code that owns it before adding more code, then report what the evidence actually proves.
