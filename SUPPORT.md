# Support

Patchy is maintained in the open. Use the channel that matches what you need:

- **Trying Patchy on a real repository:** follow the [community trial guide](docs/community-trial.md).
- **A reproducible defect, installation problem, or unclear instruction:** open a GitHub issue using the appropriate template.
- **A benchmark result, question, or idea that needs conversation:** use GitHub Discussions when it is enabled for the repository.
- **A security concern:** follow [SECURITY.md](SECURITY.md); do not disclose it publicly.

Never post credentials, private source code, customer data, or unredacted agent transcripts. A small reproducible example is more useful than a complete private repository.
