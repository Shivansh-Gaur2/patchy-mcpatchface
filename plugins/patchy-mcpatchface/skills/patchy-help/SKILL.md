# Patchy Help

Use:

- `patchy` for a feature, bug fix, refactor, or non-trivial implementation.
- `patchy-rummage` to understand code or business logic without edits.
- `patchy-review` to review an existing diff against its contract, repository fit, and available proof.
- `patchy-clipboard` remains available as a compatibility entry point for `patchy-review`.
- `patchy-factory` when you explicitly want a multi-stage task coordinated through specialist roles, isolated implementation, checks, candidate-bound review, and a saved handoff. Hosts without subagents may run supported stages sequentially, labeled honestly.

The shared promise is simple: protect stated constraints, find the behavior and the code that owns it before adding more code, then report what the evidence actually proves.
