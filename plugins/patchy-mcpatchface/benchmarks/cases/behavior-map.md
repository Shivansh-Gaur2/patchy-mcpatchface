# Behavior map

## Task shape

Explain how a user action becomes a persisted state change and an external side effect in an unfamiliar repository. Do not edit files.

## Acceptance contract

- Identify the entry point, key decisions, data movement, side effects, and major errors.
- Cite code or tests for observed facts.
- Label inferences and unknowns separately.
- Avoid narrating unrelated files.

## Score the run

Have a repository maintainer check whether the map is correct, bounded, and clear about uncertainty.
